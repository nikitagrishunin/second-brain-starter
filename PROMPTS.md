# Prompts

Copy, paste, change the parts in <angle brackets>.

## 1. Set it up (once)

Open an empty folder in Claude Code or Codex and type:

> Set up my second brain from https://github.com/nikitagrishunin/second-brain-starter. If you can't open the link, stop and tell me.

Downloaded the ZIP instead? Unzip it (you get a folder), open that folder and type:

> Set up my second brain

## 1b. Bring your old chats

Download your history: in ChatGPT - Settings → Data controls → Export data; in Claude - Settings → Privacy → Export data
(web or desktop app). You get a link by email. Put the file into inbox/ and type:

> Go through my old chats export in inbox/. Pull out facts about me, decisions with dates, and projects that are still open. Show me a list grouped by memory/, decisions.md and projects/. Save only what I approve. Don't load the whole export at once; search it piece by piece.

## 2. Every session

At the end:

> wrap up

Log a decision:

> Log this decision: <decision>, because <why>.

## 3. Find anything you've said

> Search my past sessions and this folder: what did we say about <topic>? Quote it with the date.

## 4. Keep it clean (once a week)

> Read the whole memory. Find duplicates, outdated facts and things that contradict each other. Suggest fixes as a list. Don't change anything until I say yes.

> What did I correct you on three times or more? Suggest rules for AGENTS.md, each with a "because".

## 5. Make it automatic (Claude Code)

> Set up a hook that shows me the "Next" line from the top entry in sessions.md every time a session starts.

## 6. Connect an app

> Help me connect my <Google Calendar / Gmail / Drive>. Then save my rules for it in memory: <only my main calendar; reminders one day before every bill; never delete events>.

## 7. Let it work on a schedule

Both Claude Code and Codex call these scheduled tasks.

> Every Monday at 9am: read projects/ and tell me the three most important things for this week.

> Every Sunday at 7pm: compare what I spent this week with my plan in memory/budget.md.

## 8. Teach it a task

Right after you finished a task you'll do again:

> Save how we just did this as a skill in skills/<name>/SKILL.md: when to use it, the steps, what "done" looks like, what never to do. Add one line about it under "My skills" in AGENTS.md.

## 9. Build a tool

> Build me a simple page with all my subscriptions from memory/subscriptions.md and the next charge date for each. Save how it's built in projects/subscriptions-page/STATE.md.

## 10. Light version: free plan or phone only

In ChatGPT, create a Project for one big thing in your life. Paste this into the project's instructions:

> I'm <who you are>. This project is about <goal>. How I like answers: <short first, details if I ask>. Decisions so far: <date - decision - why>. Before you answer, check these decisions. If I ask for something that contradicts one, ask me first.

At the end of every chat:

> Write a note for my next chat: what we did, what we decided and why, what's next. Under 100 words.

Paste the note into the project's instructions or as the first message of the next chat.
