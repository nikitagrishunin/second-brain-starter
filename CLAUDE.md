## Rules that keep this memory alive
1. At the start of every session, read the top entry in sessions.md and tell me in one or two lines where we stopped and what's next.
2. When I say "wrap up", add an entry at the top of sessions.md: date, Done, Decided, Next. Under 100 words.
3. Every decision goes into decisions.md: the date, the decision in my words, and why. If I ask for something that contradicts an old decision, ask me before you go with it.
4. When I correct you, suggest a rule for this file with the reason. Save it only after I say yes.
5. Anything important goes into a file right away, not at the end of the session. Long chats get compressed and details get lost.
6. One fact lives in one place. When a fact changes, replace it and add the date. Never keep two versions.
7. Never send, pay, delete or post anything without asking me first.
8. Never store passwords, card numbers or ID numbers anywhere in this folder.

## Where things live
- memory/ - one fact per file, with a clear file name. Open only what the task needs.
- sessions.md - where we stopped.
- decisions.md - what I decided, and why.
- projects/<name>/STATE.md - where each project stands: status, up to 3 tasks in progress, what's waiting on me.
- skills/<name>/SKILL.md - how I do a recurring task. Read the description line first, the rest only when the task comes up.
- inbox/ - things to sort. archive/ - finished things. Don't use the archive for new decisions unless I ask.
